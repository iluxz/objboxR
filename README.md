# The Cube — Rebuild

A WebGL void terminal. Not a benchmark. Not a toy. Something you found.

## what it is

a spinning cube that became a haunted house. gray outer cube (containment shell), 8 inner colored cubes, phong lighting, particles, audio reactivity. then the lore happened. the fps counter measures dimensional coherence. the clock shows void time. obj lives in the terminal. jbo lives in the reactor.

## features

- **3D cube** — WebGL, mouse drag rotation with momentum, scroll zoom, 5 color themes
- **cube# terminal** — full command system, virtual filesystem, package manager, voidscript scripting language
- **obj** — the void's primary interface. has opinions. does not care about your feelings.
- **reactor** — nuclear reactor sim with point kinetics, delayed neutrons, xenon-135 poisoning
- **minigames** — error page, obby, tower defense, mailroom, secret cube, casino, objpot, and more
- **audio** — void records (114+ tracks), ambient void music, audio-reactive visuals
- **skill tree** — 5 branches, 37 upgrades, economy engine
- **lore** — transmissions, lorebook, obj's story, jbo's rants
- **admin panel** — godmode, speed, broadcast, debug, freeze, noclip, override, eval
- **weather** — rain, snow, auto mode
- **day/season tracking** — weekly moods, seasonal particles
- **sorting visualizer** — 6 algorithms with audio beeps
- **BIOS/JEDEC** — black-screen POST, setup utility, timing control

## how to run

you don't. it's hosted.

- **GitHub Pages:** https://iluxz.github.io/cube-rebuild/
- **local:** `python -m http.server 8080` then open `http://localhost:8080/cube.html`

## controls

- **mouse drag** — rotate cube
- **scroll wheel** — zoom
- **1-5** — color themes
- **space** — toggle rotation
- **F3** — reactor view
- **T** — reactor terminal
- **arrow keys** — reactor navigation
- **cube# terminal** — type commands (help for list)
